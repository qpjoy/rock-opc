OPC ELK Demo App

这个页面专门用来给 Kibana 喂入几类典型日志：正常业务、慢请求、错误、认证、批处理。建议一边点击下面的场景，一边在 Kibana Discover 中使用预置 Saved Query 观察结果。

打开 Kibana 查看 Healthz

正常业务

生成 catalog 和 order 类日志，适合演示嵌套对象和业务字段。

故障与性能

生成错误和慢请求日志，适合在 Kibana 里按 log.level 与 labels.demo_scenario 过滤。

安全与审计

生成认证成功和失败事件，便于演示安全场景的日志分析。

后台任务

生成批处理与运维类事件，适合讲解 event.category 和 tags 的使用方式。
